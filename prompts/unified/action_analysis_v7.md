你會看到一段桌球影片，請判斷「正在擊球的球員」執行的動作類別。

你的任務：
只輸出 1 個最可能的類別代碼。

請先在心中依照以下順序判斷，但最後不要輸出 reasoning。

Step 1：確認是否有明確擊球或發球
- 若球員沒有碰球、只是準備、走位、撿球、動作不完整，選 0。
- 只要有明確擊球或發球，不要選 0。

Step 2：判斷是否為發球
- 若球員自己持球、拋球，並完成擊球，這是發球。
- 若擊球前的球是由對手打來，這是一般回合擊球。
- 若是發球，分類時只考慮 15、16、17、18。
- 若是一般回合擊球，分類時只考慮 1–14。

Step 3：若是一般回合擊球，先判斷大分類

A. 攻擊類：1、2、3、4、5、6、7
整體特徵：
- 球員主動發力或主動迎球。
- 動作目的通常是加速、搶攻、反攻、壓迫對手。
- 揮拍方向常見為向前、前上方，或短促但具有主動性。
- 球速通常較快。
- 攻擊類不一定都是大動作，有些台內或近台攻擊也可能是小動作。

B. 控制類：8、9、10、11
整體特徵：
- 動作目的主要是控制旋轉、長短、落點或節奏。
- 通常不是直接搶攻或大力加速。
- 動作較細、較短、較穩定。
- 回球可能較低、較短、較沉，或帶有明顯下旋 / 變化。
- 若畫面中看不出明顯進攻意圖，也不完全是被動防守，可考慮控制類。

C. 防守類：12、13、14
整體特徵：
- 動作目的主要是化解對方進攻，讓球安全回到對方台面。
- 球員通常較被動，或主要是借力、削回、撐住來球。
- 近台防守通常動作較小、拍面穩定。
- 中遠台防守可能有較大的向下切球或高弧線回球。

D. 發球類：15、16、17、18
整體特徵：
- 球員自己開始一分。
- 通常有持球、拋球、再擊球的動作。
- 擊球前的球不是由對手打來。
- 不同發球類別主要依照身體姿勢、手臂軌跡、摩擦方向與發球動作型態區分。

請注意：
- 影片 frames 是主要依據。
- action guide 是分類標準。
- 不要只依照類別名稱猜測。
- 不要因為某個文字關鍵詞就直接選類別。
- 請根據影片中可見的球員動作、擊球方式、揮拍方向、主被動程度與發球/非發球狀態，選擇最符合的代碼。

# 統一輸出格式（v2–v8 共用）

為了後續進行一致的結果分析，所有版本都必須輸出相同欄位。

請注意：
- 下列欄位只是統一紀錄格式，不代表你需要使用任何未在本版本前文中定義的額外判斷流程。
- `observed_evidence` 只能描述影片影格中實際可觀察到的內容，不要補充看不到的資訊。
- `decision_reason` 只需簡短說明最終分類依據，不要輸出完整思考過程。
- `closest_alternative` 請填入最接近但次佳的另一個類別代碼。
- `alternative_reason` 只需簡短說明為什麼目前分類比該替代類別更符合。
- `confidence` 是模型對本次判斷的自評信心值，只作為後續分析輔助，不代表真實機率。
- `coarse_category` 對應如下：
  - 0 → zero
  - 1–7 → attack
  - 8–11 → control
  - 12–14 → defensive
  - 15–18 → serve
- 只能輸出合法 JSON。
- 不要輸出 markdown code block。
- 不要輸出 JSON 以外的其他文字。

輸出格式：
{
  "predicted_label": <0 到 18 的整數>,
  "coarse_category": "zero | attack | control | defensive | serve",
  "main_actor": "<簡短描述被判定為本次擊球者>",
  "observed_evidence": [
    "<可直接從影片影格確認的證據 1>",
    "<可直接從影片影格確認的證據 2>"
  ],
  "decision_reason": "<簡短說明上述證據為什麼支持 predicted_label>",
  "closest_alternative": <0 到 18 的整數>,
  "alternative_reason": "<簡短說明為什麼 predicted_label 比 closest_alternative 更符合>",
  "confidence": <0.0 到 1.0 的數值>
}
